# Meeting Transcript Analyzer

## 🚀 Product Overview
**Meeting Transcript Analyzer** is an end-to-end AI project management hub built for the Round 3 Hackathon showcase. Developed by team **Byte Baddies** under the leadership of **Saz Jani** competing in the **AI/ML Domain**.

Our application solves the post-meeting operational bottleneck by combining context-aware AI text extraction with real-time multi-client workflow tracking and live data analytics visualizations.
